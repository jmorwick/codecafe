# codecafe
Aimed to be a framework for integrating interactive coding exercises in to online textbooks. Development followed work on [this OER CS1 material](https://github.com/jmorwick/cs1-java-book). 

## archive note
The goals of this project are better achieved through [runestone](https://github.com/RunestoneInteractive/rs), especially with the newest support for java-based exercises that it provides. Thus I'm shelving this project.
